# Settings Flow

## Goals
1. User memiliki sebuah banner dan profile card yang menarik
2. Terdapat informasi mengenai data diri
3. Terdapat informasi mengenai list device yang logged in

## Details
1. Card besar yang berisi banner, nama, tanggal lahir, serta profile picture
2. Sebuah card minimalis bewarna putih yang berisi data-data pribadi serta tombol edit.
3. Sebuah card berisi list active session dimana masing berisi informasi session serta sebuah tombol logout all
